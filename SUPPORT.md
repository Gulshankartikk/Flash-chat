# Flash Chat Support Guidelines

For user help and troubleshooting, Flash Chat includes a dedicated in-app Support Portal:
- Navigate to **Settings > Support Desk** or click **"Chat with us"**.
- Automated **Flash AI** first-response is available 24/7 for instant answers to frequently asked questions.
- For human assistance, tap **"Talk to a human"** to be connected to an on-duty support representative.

---

## Technical Bug Reports & Feature Requests

If you are a developer reporting a reproducible technical defect or contributing code, please use our [GitHub Issue Tracker](https://github.com/your-org/flash-chat/issues).

> **Security Notice**: Never post passwords, API secrets, personal phone numbers, or private chat messages in public GitHub issues.
